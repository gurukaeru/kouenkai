# 市民投稿・承認機能の導入手順

この仕組みでは、投稿された問題をGoogleスプレッドシートで管理します。投稿直後には公開されず、管理者が「承認」に変更した問題だけが後援会HPへ自動表示されます。

## 1. 管理用スプレッドシートを作る

1. 後援会で管理するGoogleアカウントで、新しいGoogleスプレッドシートを作成します。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードを消し、同梱の `Code.gs` の内容をすべて貼り付けて保存します。
4. 関数一覧から `setupSheet` を選び、「実行」を押します。
5. 初回だけGoogleの承認画面が出るので、管理用アカウントで許可します。

スプレッドシートに「投稿問題」シートができ、状態欄に「承認待ち・承認・差し戻し・非公開」の選択肢が設定されます。

## 2. 新着通知を受け取る

新しい問題が届くと、標準ではApps Scriptを設置・公開したGoogleアカウントへ通知メールを送ります。

別のメールアドレスへ通知したい場合だけ、次を設定してください。

1. Apps Script左側の「プロジェクトの設定」を開きます。
2. 「スクリプト プロパティ」に次を追加します。
   - プロパティ：`ADMIN_EMAIL`
   - 値：通知を受け取るメールアドレス

未設定でも、Apps Script所有者のGoogleアカウントへ通知されます。

設定後、関数一覧から `testNotification` を一度実行してください。「投稿通知テスト」という件名のメールが届けば設定完了です。

## 3. 投稿窓口を公開する

1. Apps Script右上の「デプロイ」→「新しいデプロイ」を開きます。
2. 種類は「ウェブアプリ」を選びます。
3. 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は「全員」にします。
4. 「デプロイ」を押し、表示された `/exec` で終わるウェブアプリURLをコピーします。

このURLは投稿の受付と、承認済み問題の読み込みにだけ使います。スプレッドシート自体を一般公開する必要はありません。

## 4. 後援会HPのクイズへ接続する

`minamisoma-shirinaosu.html` 内にある次の行を探します。

```javascript
const COMMUNITY_API_URL='';
```

手順3でコピーしたURLを入れます。

```javascript
const COMMUNITY_API_URL='https://script.google.com/macros/s/……/exec';
```

保存したHTMLを後援会HPへ掲載してください。接続後は「問題をつくる」画面の送信ボタンが自動的に有効になります。

## 日々の承認作業

1. 新しい投稿は「承認待ち」で1行追加されます。
2. 問題文、正解、解説、出典ページを確認します。
3. 必要ならセル上で文章を修正します。
4. 公開してよければ「状態」を「承認」にします。
5. クイズを次に開いたとき、「みんなの問題」と全問題モードへ自動追加されます。

公開を止める場合は状態を「非公開」または「差し戻し」に戻します。HTMLの再編集は不要です。

## 承認前チェック

- 問題文が一つの意味に読めるか
- 正解が一つに定まるか
- 現在も変わり得る情報に、時点や年月が入っているか
- 解説だけで「なぜその答えか」が分かるか
- 出典が公的機関、博物館、公式団体など信頼できるページか
- 原町・小高・鹿島のどこかだけを不必要に代表扱いしていないか
- 個人への攻撃、宣伝、政治的な誘導、個人情報が含まれていないか

## 公開前テスト

1. 後援会HP上でテスト問題を1件投稿します。
2. スプレッドシートへ「承認待ち」で入ることを確認します。
3. 状態を「承認」にします。
4. クイズを再読み込みし、「みんなの問題」に表示されることを確認します。
5. 状態を「非公開」に戻し、再読み込み後に消えることを確認します。

ローカルファイルでの表示は画面確認用です。実際の送信確認は、HTTPSで公開した後援会HP上で行ってください。

## 安全な運用

- スプレッドシートを「リンクを知っている全員」に公開しないでください。
- 「連絡先（非公開）」列は、問い合わせ対応以外に利用しないでください。
- 管理メンバー以外へ編集権限を与えないでください。
- Apps Scriptのコードを変更した場合は、「デプロイを管理」から新しいバージョンを反映してください。
